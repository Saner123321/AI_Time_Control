# 网站例外 · 备注与分组 v5

先在原窗口提交需要保留的草稿，再关闭专注计划主窗口。双击本文件夹 **更新备注与分组.exe**，点击 **更新并开始30分钟测试** 并完成管理员确认。更新后点击 **打开新版 · 管理例外**，日后继续使用桌面“专注计划（主机测试）”。本次浏览器组件不变，不需要重新加载。

更新保留原数据库、已保存规则、额度、例外和待生效申请；旧例外显示为“未分组 / 未添加备注”，原网址保持原来的匹配行为。已到期或手动停用的规则保持停用；更新按钮明确重新安排30分钟测试期限及独立恢复任务，不会自动启用规则。

## 整理例外

在规则编辑区域点击 **管理例外 · 备注 / 分组 / 搜索**：

- 每条记录显示 **分组、备注 / 用途、网址或通配符**。
- 双击一条记录，或点击“编辑选中项”，填写用途和分组。分组可以输入新名称，也可以从已有分组中选择。
- 搜索同时匹配网址、备注和分组；分组筛选可以只看课程、工具等指定类别。
- “批量粘贴”允许每行一个网址，统一填写备注和分组；重复网址保留原来的备注。
- Ctrl / Shift 多选后可统一移到某个分组；分组留空恢复“未分组”。
- 移除记录只修改草稿，提交前不改变封锁。

点 **完成编辑，回到规则草稿**，再点主窗口 **提交完整修改** 保存。

**仅修改备注和分组立即保存，不修改封锁范围，不取消待生效申请，也不重新计算等待时间。** 新增、更改网址会按原来的规则强弱判断：放宽需要延迟，收紧立即生效。分组只用于整理，不能作为开关单独停用一组网站例外。

备注最多500字，分组最多60字，均为单行。备注与分组随规则保存、重启保留，也包含在规则 JSON 导出中。空备注不会增加旧规则的存储字段；无需清空或重建数据库。

具体页面仍要求实际主机名一致，例如 `www.bilibili.com` 和 `bilibili.com` 不同；本次不会自动改写网址或扩大放行范围。新建规则不再默认启用测试用的两分钟循环，时间条件需由用户选择。
