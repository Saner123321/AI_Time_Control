# 专注计划：自用测试版 v1

**规则更新 v2：** 下文历史“时段锁 + 等待窗口”的交互已由用户修订。新版本收紧立即生效，包含放宽才等待，旧规则运行到截止时间后自动切换；界面显示当前与待生效两份配置。已安装用户见 `RULES_UPDATE_V2.md`，不需重装或重建规则。

这是用于 Windows 11 VMware 来宾的集成测试版。应用、网站、日程、额度、锁定、统计和安装入口已接入同一个后台，可以集中测试。不是完整 Cold Turkey 商业版，也尚未批准安装到物理主机。

## 安装和日常打开

1. 将 `AICT-self-use-beta-v1.zip` 复制到虚拟机，完整解压到一个新文件夹。本轮不要求先恢复快照，也不要求重启。
2. 双击解压后根目录的 **专注计划.exe**，点击“安装并开始”，完成一次管理员确认。无需打开命令行，也无需另外安装 .NET。
3. 安装成功后，日常双击桌面上的 **专注计划** 快捷方式。不要再使用旧的“专注计划（测试版）”入口或旧开发预览。
4. 首次进入“浏览器设置”，按窗口指引给要使用的 Edge / Chrome 配置文件加载组件。开发者模式只用于此次虚拟机测试；正式商店部署尚未完成。

安装文件保存在 `C:\ProgramData\AICT-Beta-会话编号`。关闭窗口不停止后台；本版没有旧实验的 60 分钟自动清理。后台意外停止时，重新打开会提供“启动 / 修复后台”，使用原数据库，不悄悄新建空白规则。

如果上次应用实验的受保护数据库还在、旧服务已移除，本版会尝试复制迁移规则、循环起点、额度与冻结修改，旧数据保留。迁移不等于取消旧锁定。旧实验仍在运行或其他策略冲突时会拒绝并行覆盖，应保留诊断结果。

## 一次配置应用与网站

- 点击“新建规则草稿”，命名后选择 EXE、填写网站，或者两者同时选择。网站每行一个，可以填写自己的域名；完整网址会提取域名，**本版不区分同一域名下的网页路径**。域名包含其子域名。
- 应用可选“封锁选中应用”或“仅允许选中应用”；网站也有黑名单、白名单。例外只影响所属规则组。多个组同时生效时，只要任一组仍要求封锁，就继续封锁。
- 应用按文件内容身份匹配，所以同一文件改名为 `Renamed.exe`、复制到其他目录，仍可能被同一条规则封锁。文件升级后需要重新登记。第一版主要覆盖普通 EXE，未承诺完整 Store/MSIX、发布者升级匹配。
- 封锁条件可以选每周时段、跨午夜时段、固定封锁/休息循环、每日额度、倒计时和全天。条件并存时，时段等硬封锁不会因尚余额度而放行。循环以固定起点运行，重开界面不重置。
- 默认上海时区，可选 UTC。每日额度按组共享，前台同时命中应用和网站只扣一次；空闲超过 60 秒、锁屏与已识别的睡眠不计入。采集缺口可见，相关额度会保守限制，不把缺口当作零使用。
- 点击“提交完整修改”才保存。本地草稿可以自由改动；界面会分别显示后台连接、应用策略读回、浏览器连接和采集状态。“规则已保存”不能代替这些执行状态。

**先用短规则测试。** 新草稿默认封锁 2 分钟、休息 1 分钟，首次配置的后续修改等待默认 1 分钟，可自行修改。正式延迟可以设为小时；建议确认功能后再设置长时间。应用白名单会结束未允许的非系统程序；先保存工作。系统目录和本软件目录保留必要例外，不承诺白名单是完整安全边界。

## 锁定与等待如何使用

“封锁条件满足时锁住修改”表示旧规则正在要求封锁时，不能立即解除。修改延迟按**当前生效的配置**计算，不能在一次解除申请中把等待时间也即时改成零。

提交修改后，整份内容冻结。等待结束且旧规则允许修改时生效；窗口里可以查看冻结内容和最早时间。撤销只保留旧规则，重新提交重新计时。停用、删除、修改网站例外、时区和正常卸载，都遵守同一个后台检查。

全天封锁与时段锁组合可能一直没有允许修改的窗口。短时测试优先用倒计时或有休息的循环，避免无意配置永久等待。倒计时的截止时间在提交时确定；有延迟的修改可能在倒计时结束后才生效，冻结内容不会在等待结束时重新计时。

## 浏览器保护

在“浏览器设置”复制组件文件夹路径，打开 `edge://extensions` 或 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，粘贴该路径。每个要使用的配置文件都要加载；返回软件刷新状态确认连接。

组件执行域名规则、现有标签页跳转和网站前台统计。后台独立控制标准安装位置的 Edge / Chrome 联网；启用网站规则期间，组件被停用、删除或失联，会限制相应浏览器联网。失联持续后会关闭一次其现有窗口，以结束已有页面和连接，随后可以重新打开离线浏览器修复组件。启用前请保存浏览器内的工作。

此回退在规则的休息时段也要求组件保持连接，以便下一时段继续执行。采集或组件恢复并确认最新规则后再解除相应联网限制。不同配置文件、IPv6、QUIC、已有连接和缓存页面的实际效果仍须本轮来宾测试，不把本地规则测试当作浏览器实测。

范围是标准安装的 Edge / Chrome。便携浏览器、其他浏览器、WebView、远程桌面、系统目录内的任意工具和管理员改策略不在本版完整覆盖保证内。浏览器策略只写指定用户；已有冲突值不覆盖，不改其他用户配置，不修改全局防火墙开关。

## 使用统计、导出和卸载

“查看使用统计”显示按日的应用与网站前台分钟数，约两秒入库。浏览器应用时间包含网页时间，两个维度不能相加当作总使用时间。未知观察单独显示为缺口，查询与 CSV 最多取最新 20,000 个聚合条目，默认保留 90 天统计。

“诊断/恢复”→“导出规则、用量和日志”，选择一个导出位置。结果为 `aict-beta-时间戳` 文件夹，包含规则 JSON、额度 CSV、应用/网站统计 CSV、后台状态与事件、采集诊断和文件哈希。默认不记录网页标题、页面内容或完整查询参数；诊断中的应用选择元数据可能包含本机路径，请按个人数据保管。事件记录是可观察的封锁/拒绝/失联，不代表所有管理员操作都能被发现。

正常卸载：在同一窗口“申请正常卸载”，或从 Windows“已安装的应用”进入。后台按锁定/等待条件批准后撤销自己的服务、任务、策略和网络过滤。保留规则/日志和一个惰性的本地桥接入口，使下次打开的浏览器配置文件可以清掉扩展持久规则并卸载组件；不会删掉其他软件配置。历史文件不自动删除。重新安装需明确点击“重新安装（新规则，历史保留）”。

## 误封时恢复

安装包与安装目录都单独提供 **管理员恢复工具.exe**。只用于误封或损坏：输入窗口指定的“我确认这是故障恢复”，点击恢复并完成管理员确认。它撤销本软件拥有的限制，保留规则与证据。若失败，保留安装目录的 `setup-result.json`、`state/operation-fault.json` 和状态文件，勿手动删除数据库。

管理员仍拥有最终控制权。独立恢复工具本身就是这一边界，不能宣传为完全防管理员绕过；本版没有禁用任务管理器，没有改变账户类型，也没有内核驱动。

## 本轮集中测试

按包内《集中测试清单.md》测试一次即可。关闭界面、结束采集、移除插件和软件内解除是本轮重点；不要求重复旧实验、恢复快照或进行重启/断电矩阵。完成后用图形界面导出上述文件夹并复制回项目 `reports`，同时说明哪一步与预期不符。

本机构建与自动检查已通过；新集成版的实际安装、AppLocker 白名单、持久 WFP、浏览器部署、采集、卸载和故障恢复均等待 VMware 来宾确认。旧实验成功不自动授予这些新路径通过。正常切换不超过两秒、额度超用不超过五秒仍是待实测目标。自动启动和持久规则已实现，但当前服务故障期间未来日程不会自行计算，完整重启/快速启动/断电/时钟异常与多版本覆盖尚未验收。
