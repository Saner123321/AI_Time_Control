# 正式内置网页观看保护 v14

适用于当前网络修复v13的本机安装。更新保留原规则、例外、额度用量、待生效修改和持续运行模式，不重置数据库，不增加60秒或30分钟截止时间。

## 更新与使用

1. 关闭之前的“内置浏览器验证”v1/v2/v3工具。
2. 从专注计划托盘右键选择“退出界面”，然后双击本目录 **更新内置浏览器保护.exe**，点击“更新并继续使用”，完成Windows管理员确认。
3. 更新后从开始菜单打开“专注计划”，查看“ChatGPT观看保护”。应显示连接与执行确认；更新器也会检查观看组件心跳、进程权限及执行回执，不仅检查规则保存。
4. 无需另建规则或安装ChatGPT插件。现有网站规则的每周时段、倒计时、循环、每日/分段共享额度、白名单和网页例外自动作用于前台可见的内置网页。Edge/Chrome仍使用0.5.0组件，无需重载。

当前普通内置网页区域的适配已由用户验证：v3遮挡看起来稳定，v2本地页面的AI读取、截图及计数点击成功。v14接入同一遮挡实现和实际后台决策，完整升级后的这台主机执行状态仍需安装后确认。

## 计时与遮挡

- 只在受管理用户的ChatGPT窗口前台、可见网页地址被确认时记录人工观看。普通聊天、隐藏的标签页、切到其他软件及后台AI浏览不计入这份观看时间。
- **前台网页可见即按观看计时**，不能检测眼睛是否在看或视频是否暂停。此模式不因键鼠60秒空闲停计，否则看视频时会漏扣；锁屏、睡眠和离开前台不计。若要临时离开，可切到其他软件或隐藏网页。
- 多个可见网页按同一规则组只扣一次；多域名统计为不同维度，不能相加当总时长。网页例外只影响所属规则组，另一组仍拒绝时继续遮挡。
- 达到时段或额度时遮挡用户看到的网页区域，显示规则原因；不关闭网页、不暂停视频、不拦ChatGPT网络、不改网页DOM，保留AI操作能力。跨日、跨时段的额度沿用原账本和重置语义。
- 允许网页的新确认立即替换旧遮挡。短暂读取中断保留最多2500ms的确认，不能自行续期；后续不确定会显示未确认，已知范围的短缺口分别记账，不能把没有观测等同于没有使用。未知状态不把整段普通聊天强算为看视频。

## 后台与普通绕过防护

观看组件独立于主界面和会话采集进程运行，由会话代理启动、检查并在退出后恢复。关闭主界面不解除限制。服务验证组件的实际程序路径、调用用户和管道对端，普通界面不能伪造观看样本。

组件首次连接后，服务仅收紧本软件观看进程的权限：SYSTEM和已提权管理员保留完整权限；普通用户新打开的结束进程权限被拒绝。本地自有进程测试实际验证了普通新终止句柄被拒绝。这不是受保护进程或管理员安全边界；管理员、文件离线修改、注入或重装仍能绕过。

普通结束采集进程不会连带关闭观看组件。服务发现采集/观看UI心跳异常时恢复自有组件。正常卸载和管理员恢复会关闭本软件的观看进程，不影响ChatGPT进程。进程权限随进程退出消失，不修改其他应用的权限。

后台暂时失联时，观看组件在已有规则范围内保留保守遮挡并继续重连；不会对ChatGPT整应用断网。不能保证后台长期故障时仍准确切换未来日程，主窗口会反映未确认/异常状态。

## 范围与诊断

目前覆盖本机Windows商店版ChatGPT的普通内置网页区域。页面识别仍依赖客户端可访问性接口；客户端升级、不支持的全屏/画中画或特殊窗口可能使保护未确认。后台音频不作为已阻止内容保证，不承诺区分人的视线与AI代为打开但人同时观看的页面。

诊断与状态记录采集/显示确认、组件是否受普通结束保护等信息，网站统计只保存域名，默认不保存完整查询参数或网页内容。看到“未确认”应导出诊断，不把它当作保护已执行。

本次构建验证：194项核心测试、10项正式观看组件测试、桌面与托盘自测、14项持续模式/计时器检查和8项更新文件恢复检查；不在开发过程中安装服务或修改主机规则。回执：`reports/manual-view-v14-local-checks-20261111.json`。
