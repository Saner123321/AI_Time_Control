# 网址与通配符更新 v4

双击本文件夹“更新网址功能.exe”，点击“更新并开始30分钟测试”，完成 Windows 管理员确认。更新短暂重启现有后台；不覆盖数据库，不清空规则、用量或待生效申请。测试到期继续保留并停用规则，独立恢复任务也会按新期限安排。此包仅更新当前这台主机的已知安装。

更新后，在 Edge / Chrome 扩展页面重新加载专注计划组件。组件应为 **0.2.0**。如果旧组件加载自最初的解压包，需移除旧组件，再加载更新窗口“复制浏览器组件文件夹路径”提供的目录。请先完成组件更新再提交网站规则；旧组件不能确认含网址/通配符的规则，后台会按组件未就绪处理。

然后点击更新窗口“打开新版并恢复网站草稿”。恢复的是刚才未提交的网站列表及例外，尚不启动封锁；请核对时间条件再提交。以后继续用桌面“专注计划（主机测试）”。不要再从旧解压包的 App 目录打开。

## 写法

| 输入 | 行为 |
|---|---|
| `bilibili.com` | 整个域名和子域名 |
| `*bilibili*` | HTTP(S) 网址中包含 bilibili |
| `*favlist*` | 网址中包含 favlist；不限于 B 站 |
| `bilibili.com/video/BV1Example` | 这个主机上的这一个页面，不包含其他子域 |
| `https://www.bilibili.com/video/BV1Example/?spm_id_from=123` | 保存为这个具体页面；忽略查询参数、片段和末尾斜杠 |
| `*://*.bilibili.com/video/*` | 主机和路径的通配符 |
| `file://*.*` | 兼容旧列表，保留但不参与 HTTP(S) 网站匹配 |

每行一条。`*` 匹配任意长度字符，`?` 不是通配符。不区分大小写。普通页面链接忽略全部查询参数，包括 `p`、`fid`；若需要区分查询内容，使用带 `*` 的完整网址模式。纯域名保持原有子域覆盖语义。收紧立即执行；新增放行例外、缩小封锁范围等修改按当前等待时间生效。复杂模式的包含关系无法证明时仍等待。

例外仅作用于所属规则组。两组规则中任一组要求封锁，仍会阻断，不能用另一组的例外抵消。

## 执行方式和边界

纯域名规则保留原有浏览器声明式网络封锁。存在页面或通配符时，浏览器在页面/内嵌页面请求发出前先转到本地确认页；组件评估所有规则，允许后仅给该标签页和精确网址临时通行。修改生效时撤销旧通行。可能短暂闪现“正在确认网址”；受限页面显示封锁原因，解除后可重试。

这种模式控制页面导航、已有标签页和浏览器报告的网址变化；不宣称能撤销所有已缓冲媒体或拦住每条后台资源连接。网站保护不覆盖 file、浏览器内部页或任意其他程序。组件失联时仍使用已有后台网络兜底。具体网址仅在组件/后台内存和浏览器临时规则中用于匹配，活动统计仍只保存域名；封锁确认页保留本次网址用于重试。

实现依据：[Chrome 声明式规则与标签页会话规则](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest)。

本地验证：核心规则、额度、延迟与恢复回归；组件模拟；Edge 与 Chrome 的独立测试配置，确认受限请求未到达测试服务器、页面例外正常、多组交叉封锁有效、撤销例外后不复用旧通行、清空规则恢复访问。实际主机更新和真实站点使用仍需安装后确认。
