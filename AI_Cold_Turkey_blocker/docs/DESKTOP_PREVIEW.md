# 桌面与后台开发预览

这是规则工作流的开发预览，**不会封锁任何应用或网站，也不具备防结束进程能力**。
阶段0仍未整体验收通过。当前界面用于检查真实的规则编辑、后台校验、冻结修改和SQLite保存流程，
不表示系统执行层已经接通，不应用来承担自控任务。

## 启动与退出

在构建产物中双击 `App\Aict.Desktop.exe`。不需要管理员权限或全局.NET安装；使用包内自带运行时。
后台为同账户下的普通进程，不注册Windows服务、计划任务或开机启动，也不写系统策略或网络过滤。
首次启动在本包根目录的 `data` 文件夹创建预览SQLite数据库和应用显示名称。
请将整个产物放在自己的可写文件夹，不要只复制单个EXE。

关闭窗口后，后台仍继续计算预览中的修改等待并保存状态。后台故障或重启不会被本预览自动保护。
完全退出预览时，在产物父目录的PowerShell运行（文件夹名称替换成实际构建文件夹）：

```powershell
.\desktop-preview-TIMESTAMP\Stop-Preview.ps1
```

退出脚本核对本包后台的完整路径、进程号和启动时间；任何不匹配都会拒绝结束进程。
这是开发预览的退出工具，不是正式产品的卸载、服务控制或解除锁定接口。
预览配置保留在 `data` 中；脚本不删除它。不要依赖此普通用户可改的数据来防篡改。

## 编辑流程

- 支持多组规则、应用/网站黑白名单、组内例外、多个星期时段、跨午夜、每日共享额度和固定起点循环。
- 应用选择只读调用Windows PE SIP SHA256身份接口，不执行选中的应用，不使用文件名作为封锁身份。
  只支持当前版本的常规EXE；不是发布者规则，文件更新后需要重新选择。Store/MSIX和正式系统必需应用清单待接入。
- 界面填写的是草稿；点击提交才向后台发送完整目标配置。切换规则或放弃草稿会丢弃未提交的界面内容。
- 后台决定当前延迟和锁定；待生效内容按提交时冻结。已有待生效修改时，必须先撤销再提交，重新开始等待。
- 当前空白预览配置的延迟为0，便于第一次保存；编辑器默认将下一次修改的延迟设为24小时。
  第一次保存后，即使把输入框改为0，本次仍需服从旧配置的24小时等待。
- 前台采集和扩展未连接，所有实际额度显示未知；有额度且锁定的规则可能因此一直等待，属于缺失遥测时的保守判断。
  这不代表封锁已执行。预览没有提供跳过等待或回填使用量的按钮/API。
- 周期锚点随规则持久化；已有周期再次编辑不自动重设起点。当前日历仅支持上海和UTC。
- 本包 `data` 是独立开发数据。不要用它替换任何原始来宾实验报告或将来正式安装的数据。

## 后台通信与持久化

`Aict.Backend`独立进程持有状态；`Aict.Contracts`定义有界命名管道协议；`Aict.Desktop`只负责界面。
协议只提供查询、提交目标配置、撤销指定待生效修改和导出，不接受客户端的时间、额度、整份状态、数据库路径或命令行。
编辑令牌绑定当前配置和待生效修改，后台序列化请求，拒绝旧草稿覆盖。普通计时检查点不会使草稿失效。
更改只有SQLite事务成功后才返回成功。数据库损坏或出现并发写入时停止接受修改，不清空数据库。
管道只允许当前Windows账户，最多8个连接，请求256KiB、响应8MiB，单连接8秒超时。
**当前账户约束不能直接用于将来的LocalSystem服务**：正式服务需要指定被管理用户的独立ACL和调用身份验证。

后台每秒调度、每5秒持久化计时检查点；提交与撤销同步持久化。每秒调度不是实际封锁两秒目标的验收。
预览重开时以系统时间建立**模拟时间锚**，不接受低于已保存时间高水位的时间。
运行中由单调时间推进、系统时间用于诊断。正式可信重启时间源、睡眠校对和离线恢复尚未实现。
预览不能证明抗时钟篡改或跨重启实际防护，不复用为正式安全承诺。

JSON导出带有开发预览、遥测缺失标识；CSV仅导出数据库现有额度记录，空表不表示没有使用。
导出内容由普通权限界面在用户选定位置保存；后台不接受任意写文件路径。
完整事件历史、90天留存和真实应用/网站使用区间尚未实现，当前没有伪造“违规次数”或“已封锁时长”。

## 开发与验证

在 `D:\Projects\AI_Time_Control` 运行：

```powershell
.\AI_Cold_Turkey_blocker\scripts\Test-Core.ps1
.\AI_Cold_Turkey_blocker\scripts\Build-Preview.ps1 -SelfTest
```

构建使用项目私有SDK与NuGet缓存，输出独立时间戳产物。自测只启动本程序，验证后台连接、草稿校验、导出与窗口渲染，
然后核对身份并退出后台。渲染图和结果在产物的 `ui-self-test` 中，测试数据库在 `ui-self-test-data`，普通预览数据仍为空。
`pipe-smoke` 另外记录真实管道的协议拒绝、冻结内容、撤销及后台重开检查；这些测试都只启动普通进程。
界面自测不是实际点击操作、受限用户身份验证、系统重启或AppLocker/WFP验收的替代品。
下一步仍是VM内的正式服务/执行层联调与故障恢复，不在主机上安装封锁。
