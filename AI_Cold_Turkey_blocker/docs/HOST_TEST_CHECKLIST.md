# 首次安装后的检查

1. 双击完整包根目录的“专注计划.exe”安装，从开始菜单进入。确认首次安装为空规则、后台已连接；默认持续运行，没有统一的30分钟截止时间。
2. 保存工作，先选择包内无害应用或一个明确要限制的 EXE，使用 1—2 分钟短规则。首次暂不开应用白名单。
3. 按“浏览器设置”给本机 Edge / Chrome 加载组件，确认连接后，添加一个网站及例外。然后清空网站列表并提交，等待生效后从新标签页打开原网站，检查恢复访问。原封锁页可点“重新尝试打开网站”。
4. 尝试关闭窗口、再从托盘或开始菜单打开；检查当前规则和待生效规则。收紧立即执行，放宽按已有等待时间，到期自动更换。
5. 检查“软件设置”的界面自启动，以及网页观看保护的实际连接和执行状态。“诊断/恢复”可导出规则、用量和日志。误封或后台损坏时使用独立“管理员恢复工具.exe”。

组件失联等故障检查可在熟悉功能并保存工作后进行：受管理浏览器可能暂时限制联网；ChatGPT内置网页采用观看区域遮挡。其他用户电脑上的安装、重启和兼容表现仍需实际确认，开发者本机通过的结果不自动适用于所有电脑。
