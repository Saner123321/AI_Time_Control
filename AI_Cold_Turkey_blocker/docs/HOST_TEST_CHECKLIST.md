# 主机首轮使用

1. 双击“专注计划.exe”安装，从桌面“专注计划（主机测试）”进入。先确认初始无生效规则、后台已连接；截止时间会显示在顶部。
2. 保存工作，先选择包内无害应用或一个明确要限制的 EXE，使用 1—2 分钟短规则。首次暂不开应用白名单。
3. 按“浏览器设置”给本机 Edge / Chrome 加载组件，确认连接后，添加一个网站及例外。然后清空网站列表并提交，等待生效后从新标签页打开原网站，检查恢复访问。原封锁页可点“重新尝试打开网站”。
4. 尝试关闭界面、再从桌面打开；检查当前规则和待生效规则。收紧立即执行，放宽按已有等待时间，到期自动更换。
5. 30 分钟到期后应保留并停用规则，恢复访问。“诊断/恢复”可导出规则、用量和日志。误封或后台损坏时使用独立“管理员恢复工具.exe”。

组件失联测试可以等上述功能正常后再做：它会暂时限制浏览器联网并可能关闭一次现有窗口，先保存网页中的工作。没有要求再次去虚拟机重跑旧实验。
