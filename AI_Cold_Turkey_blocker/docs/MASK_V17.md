# 实际遮挡与置顶修复 v17

适用于后台检测v16。托盘右键“退出界面”，双击“修复网页遮挡.exe”，点击“更新并修复遮挡”，完成管理员确认；从开始菜单重新打开即可。无需重启电脑或ChatGPT，无需重载浏览器组件。

本机只读检查已确认：首页已被识别，下午20分钟额度耗尽，后台要求遮挡1页并收到“已遮挡1页”的回执；但原生遮挡窗口没有WS_EX_TOPMOST，在连续30次采样中都不是实际置顶窗口，会被前台ChatGPT盖住。程序内部TopMost/Visible属性与真正呈现状态不一致，旧回执只统计了Place调用成功，不能证明用户看到遮挡。此前含history来源参数的视频还命中过宽泛例外，这是单独的规则问题，不能解释首页漏遮挡。

此版在Place完成后核对原生窗口的可见、置顶、实际矩形及DWM未隐藏状态。读回不满足时才以HWND_TOPMOST、NOACTIVATE恢复显示和位置，再次读回失败则报告未确认。健康状态不重复修改原生位置或截图排除属性，保留原有防闪行为，不抢焦点。遮挡回执只在实际读回通过后计数；一组窗口显示失败时清空所有本轮回执，避免隐藏窗口后仍上报已遮挡。

网页未识别时也不再把空窗口集合标记为已执行。更新器区分“采集组件已就绪”和“当前网页已执行”：没有可识别网页时可完成组件更新，主窗口仍显示未识别；有明确应遮挡网页时必须确认实际显示。不会把未识别的整段聊天算成视频，也不因此封锁ChatGPT联网。

原规则、例外、额度、待生效修改和自启动选择保留。未改变通配符匹配语义；例外仍按原配置放行。AI截图排除和点击穿透保留。

本地195项核心测试、19项观看组件检查、13项自启动检查、7项更新就绪判定及8项更新文件恢复检查通过。新增夹具实际降低自有窗口层级，再验证恢复置顶且不重设截图排除；连续100次健康放置不增加原生修复写入。上述夹具不安装主机服务，不改变当前ChatGPT窗口，最终主机效果由用户更新后确认。
