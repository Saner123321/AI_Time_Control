# 内置浏览器验证 v3：减少遮挡闪烁

保持v2的独立验证定位，尚未接入正式封锁日程或额度。关闭v2工具后再运行 **内置浏览器验证-v3.exe**，复制新的本地验证页网址，手动粘贴到ChatGPT内置浏览器，再开始自动遮挡验证。原正式服务和规则不改。

## 本次修正

v2每100毫秒会重复设置窗口截图排除与透明属性，并强制重绘。v3改为每个遮挡窗口句柄仅初始化一次；区域和显示状态不变时不做原生写入、不强制重画，移动时也不重设截图排除。实际系统曝光或尺寸变化仍会正常绘制。

自动模式新增最多2500毫秒的确认租约：只有真实确认的网页样本续期；短暂读取失败不立即反复隐藏/显示。轮询本身不会续期。前台窗口或位置变化会立即停止显示；已确认切换到允许网页会立即替换旧样本；隐藏或歧义状态清除确认，不借用旧网页一直显示。

报告增加每次实际显示/隐藏的原因，以及窗口初始化、位置变更、显示/隐藏、绘制计数。若仍闪烁，导出后点 **复制报告路径** 发来，可区分反复重建图层、读取丢帧、窗口变化和前台切换。

## 验证状态

2026-11-11用户报告v2自动模式已出现遮挡但会闪。本聊天通过浏览器工具读取了本地测试页，截图中页面可见，点击后计数从0变为1，已保存本地证据。由于用户报告存在闪烁，不能据此确认遮挡始终连续或所有AI捕获方式都兼容。证据不上传源码仓库。

v3本地自测增加：同区域连续100次请求不重复原生写入、不重复显示；移动不重设截图排除；隐藏再显示复用句柄保护；确认租约到期、不因轮询续期、前台/位置边界、允许页面立即替换与隐藏状态失效。实际连续观看效果仍需用户运行后确认。

## 操作

1. 关闭旧验证工具，打开本目录的v3。正式“专注计划”不用关闭。
2. 点“复制本地验证页网址”，手动粘贴到ChatGPT内置浏览器。
3. 点“开始60秒遮挡验证”，切回ChatGPT，重点观察遮挡是否连续。需要时仍可使用“手动框选”，该模式不代表自动识别通过。
4. 切到其他软件、关闭工具或60秒到期会撤掉遮挡。
5. 点“导出验证结果”，在弹窗点“复制报告路径”，直接粘贴到聊天。

本工具不关闭页面、不暂停视频、不改网络/客户端设置。不保证音频、画中画、全屏或正式防绕过。截图排除和点击穿透只作用于自有遮挡窗口；实际AI效果与连续遮挡分别验收。
