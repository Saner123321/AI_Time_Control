# 专注计划 · 开始菜单图标

双击 **添加开始菜单图标.exe**，点击“添加开始菜单图标”即可。不需要关闭专注计划，不需要管理员确认，不修改封锁、额度或后台服务。

工具为当前用户开始菜单中的“专注计划”设置与托盘一致的青色时钟图标，保留已有快捷方式的目标与启动参数。缺少入口时创建；同名入口若指向其他程序则停止。不会创建桌面快捷方式。图标复制到当前用户的本地应用数据 AICT/Assets 下，删除本更新包不会丢失图标。

Windows已固定的图块可能缓存旧图标。如固定区域仍未刷新，请取消固定，从“所有应用”中的“专注计划”重新固定一次；无需重启资源管理器。

后续源码构建的主程序和安装入口也嵌入16至256像素的多尺寸图标。新安装和当前维护的后续更新模板改为开始菜单入口，不再默认创建桌面快捷方式。已交付的历史更新包保持冻结；如果仍要安装此前网络修复包，请先完成它，再运行本图标工具。

本地验证只在项目内创建临时快捷方式，核对图标资源、已有参数和同名其他目标保护，没有操作用户真实开始菜单或桌面。实际图标显示由用户运行工具后确认。
