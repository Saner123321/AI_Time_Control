# 封锁原因显示 v8

网站封锁页现在显示命中的规则名称和具体原因：

- 全天封锁。
- 每周硬封锁的起止时间。
- 循环计划正在封锁，本轮的结束时间。
- 倒计时尚未结束，以及截止时间。
- 哪个独立额度时段、多少分钟已经用完，以及该时段何时结束。
- 使用记录缺失或系统时间校验异常导致的保守限制。

多个规则或多个条件同时命中时，会分别列出。只有真正限制当前网址的规则会出现在网站页面上；该网址被本组例外放行时，不列入这组的原因。解除后会清除旧原因，显示允许重试；组件失联时显示“尚未确认”，不会把旧原因当成已确认状态。

软件主窗口会显示所选规则的当前触发条件，点击“查看当前封锁原因”可看所有当前已生效规则。这里展示规则的触发状态，具体网址是否被例外放行以网站封锁页为准。Windows 自己的 AppLocker 系统拒绝对话框保持原样，软件主窗口可查询相关规则条件。

## 更新

先保存想保留的草稿，关闭专注计划旧窗口，再双击本文件夹 **更新封锁原因.exe**，完成“更新并开始30分钟测试”及管理员确认。原规则、例外备注、额度及待生效申请保留；已停用规则不自动启用。

本次浏览器组件有更新，需在扩展管理页面重新加载到 **0.3.0**。使用更新窗口提供的安装目录组件路径；如果原组件还加载自旧解压包，则改为加载该安装目录。完成后再开始网站测试。

单纯域名规则的页面导航也会进入本机原因页；原有域名子资源网络封锁保留。页面通过当前所有规则检查后，只在对应标签页对精确网址临时通行，规则变化撤销旧通行。不是网页内容解密或远程页面服务。

截止时间按规则当前时区显示。某一条件结束不代表所有条件结束，仍以页面列出的其他规则为准。原因文本直接由后台实际规则状态生成，不从用户输入猜测；规则名称和说明使用纯文本渲染，不当作HTML执行。

## 验证与源码

155项核心测试、15项组件测试及桌面界面自测通过，覆盖各类原因、多个命中规则、例外筛选、解除清理和文本渲染。独立浏览器测试只使用本机无个人数据的测试页面，不操作用户当前浏览器界面。具体浏览器实测记录和更新器8项文件替换/恢复检查保存在本地回执中，不随源码上传个人诊断数据。

项目源码同步至用户指定的私有仓库，仅包含封锁软件、测试与必要构建夹具，不含个人规则数据库、运行日志、完整安装包或其他项目。
