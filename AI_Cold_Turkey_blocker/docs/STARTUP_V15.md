# 开机自启动 v15

适用于已安装正式观看保护v14的本机。保留原规则、用量、待生效修改、持续模式与浏览器组件0.5.0。

1. 托盘右键“退出界面”，双击本目录“更新开机自启动.exe”，点击“更新并开启自启动”，完成管理员确认。
2. 更新成功后点“打开专注计划”或使用开始菜单入口，在主窗口左上方“软件设置”中查看“开机自启动”。首次配置默认开启，以后关闭的选择在修复、更新、再次打开时保留。
3. 下次登录Windows后自动显示托盘图标，不弹出主窗口。双击图标或开始菜单入口打开；叉号隐藏，右键“退出界面”退出本次界面进程。再次登录仍按自启动设置执行。

后台服务原本就随系统自动启动，采集代理及内置网页观看保护原本就在用户登录时自动运行。这次增加的是界面/托盘自启动。关闭界面自启动不解除封锁，也不停止采集和观看保护。退出界面不会立即重启界面，但下一次登录仍会自动启动。

采用Windows当前用户Run启动入口，指向受保护安装目录内的程序，带`--startup`参数，普通权限运行，不在登录时请求管理员权限。启动时最多等待后台30秒，然后驻留托盘；后台不可用时，打开主窗口会显示连接失败，不自动弹出安装/修复向导。重复自启动不会唤起已有主窗口，手动开始菜单入口仍能唤回。开发目录和已清理的安装不能通过此参数自动安装或恢复封锁。运行自启动命令时不反复写入Run项。

只管理当前安装的独立启动值，不覆盖或清除其他软件的入口；正常卸载/管理员恢复清除匹配的自有入口。用户未登录导致其注册表不可用时清理会记录延后，残留入口启动后识别清理标记并退出。Windows本身仍可在“设置 → 应用 → 启动”禁用启动项；界面开关显示软件入口是否注册，不宣称覆盖Windows自己的禁用设置。启动行为依据[微软Run文档](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)。

本地测试使用独立内存设置夹具与模拟托盘，不修改真实Run注册表，不安装主机服务，不进行真实注销/重启。最终登录后的托盘表现需用户更新后确认。自启动错误记录于`%LOCALAPPDATA%\AICT\desktop-startup.log`，有大小限制，不弹出错误框干扰登录。
