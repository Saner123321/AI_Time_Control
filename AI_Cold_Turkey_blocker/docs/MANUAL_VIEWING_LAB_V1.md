# ChatGPT 内置浏览器：只限制人工观看的独立验证

目标是限制你使用内置浏览器观看指定网站的视频，保留AI读取、截图和操作该网站的能力。本工具验证接入条件，**尚未接入正式日程、额度、例外和服务防护**，不能当作已完成的强制封锁功能。

## 使用

建议先验证本地页面：点击“复制本地验证页网址”，手动粘贴到ChatGPT内置浏览器；工具将目标切为 `127.0.0.1`。再开启只读检测和60秒遮挡，切回测试页，让AI读取标题、截图，并点击“增加测试计数”。这样不用登录或改动任何真实视频页面。页面仅由本工具临时监听随机本机回环端口，关闭工具就停止，不能读取文件或控制本机。网址包含随机路径，不上传也不保存在导出中。

1. 双击 **内置浏览器验证.exe**。无需管理员权限、不用关闭专注计划，不创建桌面或开始菜单入口。
2. 填写验证目标域名，例如 `bilibili.com`，点击“开始只读检测”，再手动切到ChatGPT并显示该网站的视频页。检测不会导航、关闭、暂停或改动页面。
3. 回到验证工具，查看是否已识别网页域名。若当前前台是本工具，会提示“当前不是ChatGPT前台”；此前读到的状态可导出查看。这是正常的前台限定，不代表后台AI浏览被计费。
4. 点击“开始60秒遮挡验证”，立即切回ChatGPT的视频页面。只有读取到**已提交的文档网址**且区域明确才遮挡；不依据标签标题、历史访问或可任意编辑的地址栏猜测。遮挡只覆盖识别到的网页内容区域。
5. 保持视频页在前台，检查你看不到视频时，AI能否继续读取、截图并点击该页面。验证工具申请了Windows的截图排除和点击穿透，但实际AI使用的捕获方式仍须核验。
6. 60秒后自动撤掉遮挡。随时切到其他软件、回到验证工具点“停止并撤掉遮挡”或关闭工具也会撤掉遮挡。
7. 点击“导出验证结果”，把弹出的 `reports/manual-view-时间` 文件夹路径提供给开发者。导出仅包含状态、域名、区域与耗时，不包含完整网址、查询参数、页面标题、聊天内容或截图。

验证名单是独立域名，不是正式规则；工具不读取你已有的网页例外。因此本轮即使某个网页在正式例外中，也可能被你手动启动的遮挡测试覆盖。它不会消耗或退还正式额度。

## 实现边界

- 仅识别前台的已知Windows商店版ChatGPT客户端，从Windows Active Accessibility的文档对象读取网址和屏幕边界。只读文档属性，遇到文档即停止向下读取，不遍历页面正文。地址栏文本不是可信的已提交地址。
- 整个读取放在独立子进程中，父进程限时结束自有子进程，子进程也有退出看门狗。不结束ChatGPT或浏览器进程。
- 无可靠网址、区域重叠、读取超时、窗口移动、失去前台或样本过期时撤掉验证遮挡；显示“未确认”，不伪装成已经保护。此行为目前只适合验证，尚未具备正式防绕过保证。
- 遮挡是独立的本机窗口。它请求不激活、不接收鼠标点击和 `WDA_EXCLUDEFROMCAPTURE`，读回确认截图排除后才显示；不插入网页脚本、不拦网络请求、不改系统代理或ChatGPT管理策略。
- 能否识别这台机器的内置网页，不能用AI工具本身可列举标签页来代替证明。当前工具也没有使用AI会话专属的浏览器接口、会话凭据或调试端口作为后台服务能力。
- Windows截图排除属于特定捕获API的行为，不承诺所有截图方式都看不到遮挡。必须分别验证实际AI的页面截图和屏幕截图、点击与文字读取，再决定是否接正式服务。
- 本轮不保证全屏、画中画、弹出窗口、多屏裁剪、后台音频或被其他窗口局部遮住时的观看统计；未实现额度扣费。不修改客户端程序、扩展权限或全局开发环境。
- 若网址读取或AI不受影响这两个关键条件失败，保持未集成，不退化为对ChatGPT整应用断网或针对AI的网站拒绝规则。

## 本地核验与来源

自测在项目内的自有离屏窗口进行，检查文档网址与可编辑地址栏的区别、域名边界、不确定状态、截图排除读回、点击穿透样式、不抢前台和子进程数据传递。自测不是对用户正在使用的ChatGPT或真实AI截图/点击的验收。回执：`reports/manual-view-lab-v1-local-checks.json`。

Windows原生接口参考：[Active Accessibility读取接口](https://learn.microsoft.com/en-us/windows/win32/api/oleacc/nf-oleacc-accessibleobjectfromwindow)、[截图排除](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)。[OpenAI浏览器管理文档](https://learn.chatgpt.com/docs/enterprise/managed-configuration#control-browser-and-computer-use)区分AI驱动的Browser Use、Computer Use及内置浏览器面板；这些管理策略不直接满足本任务保留AI访问的要求。
