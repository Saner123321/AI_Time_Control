# 持续使用 v10

之前每次更新都重新开启30分钟测试，是沿用了早期主机误封保护。v10将日常使用改为**持续运行**：没有统一到期时间，规则按你设置的星期、时段、循环、倒计时、额度及延迟修改执行，关闭界面不会解除限制。

## 已有安装更新

关闭专注计划主窗口，双击 **更新为持续使用.exe**，点击“更新并持续使用”，完成管理员确认。适配现有 v8、v9，以及重复执行本更新的同一安装。保留数据库、用量、例外备注、延迟设置和仍有效的待生效申请；已经因旧测试到期而停用的规则不会自动开启，先核对后自行开启需要的规则。

更新取消旧的30分钟截止时间，停用并撤销本软件的旧自动恢复任务；服务还会识别并忽略误触发的旧测试恢复命令。正常卸载、规则放宽仍按原有后台检查执行。独立管理员故障恢复入口继续保留，专用于误封或损坏恢复。

浏览器组件仍为 **0.4.0**，包含减少网页中转闪屏及封锁原因功能。已经是0.4.0无需为本次后台模式变更重载；从v8直接更新时，需在扩展管理页重新加载到0.4.0，再刷新网页。原先加载自旧解压包的组件应改用更新窗口提供的安装目录组件路径。

更新后桌面提供“专注计划”入口（同名无关快捷方式存在时使用“专注计划（持续使用）”），主窗口显示“持续使用”，不再出现统一测试截止时间。旧的主机测试快捷方式若仍指向同一安装，也会打开新版。

## 新安装与可选短测

从源码构建主机包后，安装向导默认持续使用。仅在**新安装**时可主动勾选“仅试用30分钟，到期保留并停用规则”；这是可选的验证方式，不是普通规则编辑界面中的解除按钮。已有安装的修复保留原模式，不延长测试、不重置数据库、不自动切换模式。

历史 `HOST_TRIAL` 构建标记和 `hostTrial` 配置字段保留用于兼容主机身份判断；是否短测由受管理员权限保护的 `continuousUse` 和 `hostTrialEndsUtc` 共同决定，不能从普通规则编辑接口修改。持续使用必须显式为true且截止时间为空；旧短测必须有截止时间。配置不一致会拒绝启动。

应用白名单仍维持主机版原限制，未因取消短时测试而开放。管理员仍具有最终系统控制权；本次不是对所有 Windows 版本和重启/断电情形的完整验收。

## 验证与恢复

核心回归包含超过30分钟仍生效、服务重建后规则/待生效截止时间保留、可选短测正常到期、模式配置校验及旧安全命令不会解除持续规则。文件系统替换/恢复和模式迁移测试采用本地夹具及明确的系统任务替代对象，不创建真实服务或修改现有策略。

更新前备份原程序和配置；启动新版前失败会尽力恢复原程序和原模式。只有原来的有限测试配置恢复后，才重新启用其原到期任务；新版开始启动后不自动回滚数据库，也不重新启用旧计时任务。失败请保留更新目录的 `update-result.json`；确实误封时使用独立管理员故障恢复入口。
