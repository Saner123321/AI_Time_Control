# 自用版优先范围（2026-11-03调整）

用户最新目标：抵抗日常的解除冲动，主要包括退出软件、任务管理器结束进程、卸掉浏览器扩展，以及在软件中改时间段或关闭限制。
重启、离线修改、安全模式等更进一步的绕过不作为首个可用版本的重点。
此次调整缩小防绕过与故障验收范围，原有日程、额度、白名单、循环、锁定和导出需求保留。

## 首个可用版本的验收重点

- 关闭界面、退出托盘、结束普通会话代理不解除现有规则；界面从后台取得真实状态。
- 实际任务管理器操作按“结束进程也不能即时解除封锁”验收，不承诺普通服务进程绝对无法结束。
  系统执行策略独立于界面/后台寿命，后台故障由Windows恢复。已提权任务管理器必须单独实测，不能用Limited令牌证明代替。
- 修改时段、停用、删除、导入覆盖及正常卸载请求均由后台检查锁定；冻结的完整修改不能在等待结束后替换为新内容。
- 卸载/停用插件或插件失联不能触发放行。浏览器策略适用时可承担基础封锁；插件失联的保守回退要真实验证。
  原生策略在个人配置文件、已有页面、动态导航等场景的限制需验证，不先宣称只靠原生URL列表已覆盖全部情况。
- 正常退出限制、更新与故障恢复能够撤销本软件拥有的规则，保留其他配置。不能靠误封、数据库清空或长期失去计时来实现强制性。
- 基本持久化和已有规则跨后台恢复仍保留；首次主机安装/强制封锁仍需另行确认。

完整冷启动、快速启动、睡眠/断电、多版本矩阵、完整防篡改、WFP启动过滤和扩展商店发布等验收后移；
不再把完整旧阶段0矩阵作为第一版自用闭环的必经完成条件。旧实验结果与未测试状态保留，不改写为通过。
