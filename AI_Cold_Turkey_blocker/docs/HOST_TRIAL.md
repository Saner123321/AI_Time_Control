# 专注计划：主机短时测试版 v1

按用户本轮决定，后续功能问题直接在主机测试，不再要求先在虚拟机跑完功能矩阵。这是单独构建的主机包；旧 VM 包仍保留原限制与证据。

## 打开与安装

直接双击交付文件夹的 **专注计划.exe**，点击“安装并开始”，完成当前账户的 Windows 管理员确认。也可将同名 ZIP 完整解压后打开。自带运行时，无需命令行或安装开发工具。

成功后使用桌面 **专注计划（主机测试）** 快捷方式。初始为空规则，不迁移虚拟机的封锁对象；安装本身不启用应用或网站封锁。若原有系统应用策略发生冲突，界面和安装报告会报错，程序不覆盖其他管理工具的策略。

进入“浏览器设置”，按指引在要使用的 Edge / Chrome 配置文件加载组件一次。主机首次需重新加载本机安装目录的组件，不能选择虚拟机里的路径。当前仍为本地组件测试，不是商店强制部署已完成。

## 首轮范围

- 从安装开始计时 **30 分钟**；界面显示截止时间。到期保留规则、用量、日志，自动停用规则并取消待生效申请，拒绝再次启用。正常情况下后台保留，可继续查看和导出数据。
- 有独立的 SYSTEM 安全任务，在截止时间后约 1 分钟检查后台是否已确认解除；后台失联、读回不完整时会尝试撤销本软件的服务、应用策略和网络过滤，数据仍保留。它使用 Windows 任务计划机制，不保证电脑关机或任何系统故障下都准时运行。
- 仅管理当前指定用户。应用黑名单按选定 EXE 的文件身份阻断，改名/复制仍可能匹配；首次暂不开应用白名单，以减少关闭无关工作的风险。
- 网站支持自定义域名与例外、日程、循环和额度。组件失联期间，受管理浏览器可能暂时断网并被关闭一次，请先保存工作。其他浏览器、便携浏览器和 WebView 仍不在完整覆盖承诺内。
- 修改逻辑沿用 v2：收紧立即生效；包含放宽的修改才等待，到期自动切换；“正在生效 / 待生效”分别显示。先用 1 分钟等待、1—2 分钟封锁测试。

管理员仍拥有最终控制权。此包没有自研内核驱动、进程注入或 HTTPS 解密，不关闭 Windows 安全功能；不声称已完成正式安全审计、长期锁定或完整断电/重启/升级矩阵验收。

## 本轮网站问题的修复

回传 `aict-beta-20261103T110547662Z` 中，网站列表已经为空且没有待生效修改，后台仍要求网站保护，组件没有确认最新计划，网络兜底同时报错。

已修正：

1. 空网站黑名单视为没有网站限制，不再生成规则或要求浏览器保持保护；空白名单仍表示仅允许空集合，二者明确区分。
2. 浏览器生成器过滤空黑名单，撤销旧动态规则；真实 worker 的模拟浏览器接口测试覆盖了规则清空和失败时不确认生效。
3. WFP 用户条件改用 Windows 官方定义的安全描述符类型；内存中的描述符由 Windows 验证，执行错误会显示“状态未确认”，不再把失败当作已断网。
4. 原封锁页会查询当前状态，解除后显示“限制已解除”，保留重新打开链接。原封锁页本身不会自动变成网站内容，可点击重新打开。

这些改动已通过本地规则、浏览器 worker 与 Windows 描述符检查；主机上的实际浏览器行为以接下来的使用结果为准。

## 解除、恢复与回传

正常解除：停用规则，或清空网站黑名单/选择“不限制网站”，按当前等待时间生效后，新开目标网址确认。若仍停留在本软件的封锁页，点“重新尝试打开网站”。

正常卸载：从“诊断/恢复”申请卸载，同样服从当前等待条件。30 分钟期满后，测试保护已停用，允许正常卸载。组件和日志可保留少量惰性桥接入口，供下次打开的浏览器清理持久规则。

误封或后台损坏：双击包内 **管理员恢复工具.exe**，输入窗口要求的 **我确认这是故障恢复**，完成管理员确认。工具会分别尝试应用与网络恢复，仅撤销本软件拥有的对象，不删除数据库。若用户尚未登录导致个人配置未加载，网络与应用解除先尝试执行，注册表清理可能延后；登录后可再次运行恢复工具。

测试后通过“诊断/恢复 → 导出规则、用量和日志”导出，回传整个 `aict-beta-时间戳` 文件夹。安装即失败时，回传交付文件夹生成的 `setup-result.json`；保留旧报告和数据库。
